Политика конфиденциальности

Приложение Assistant — личный инструмент одного пользователя, его владельца. Доступ к данным Google (Календарь, Gmail — только чтение) владелец даёт сам себе.

  • Данные используются только чтобы показывать владельцу его собственные события, письма и дедлайны.
  • Данные не продаются, не передаются и не показываются третьим лицам.
  • Данные хранятся на личном сервере владельца; токены доступа — в закрытом файле.
  • Доступ можно отозвать в любой момент: myaccount.google.com/permissions.

Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.
